## Commands

All commands run from the **monorepo root** unless noted.

```bash
npm run dev          # Start API (port 3000) and web dev server (port 3001) concurrently
npm run build        # Production build of all packages
npm run test         # Run all Vitest unit tests across packages
npm run test:types   # TypeScript type checking across packages
npm run test:e2e     # Run Playwright end-to-end tests (starts servers automatically)
```

### API-specific (run from `packages/api/`)
```bash
npm run db:generate  # Generate a new Drizzle migration from schema changes
npm run db:migrate   # Apply pending migrations (also runs automatically on dev/start)
npm run generate:spec # Generate openapi.json from the running API
```

### Web-specific (run from `packages/web/`)
```bash
npm run generate:api-client  # Generate schema.d.ts from packages/api/openapi.json
```

## Architecture

This is a **Financial Planner** monorepo with three packages:

```
packages/
  api/   – Fastify REST API (port 3000)
  web/   – React SPA (port 3001)
  e2e/   – Playwright end-to-end tests
```

Environment is configured in `.env.development` at the monorepo root (shared by all packages).

## API (`packages/api/`)

### Tech Stack
- **Fastify** with `fastify-type-provider-zod` — request/response validation via Zod
- **Drizzle ORM** + **better-sqlite3** — SQLite database with FK enforcement
- **@fastify/swagger** — generates `openapi.json` from route schemas

### Domain structure

Each domain follows the same 6-file pattern (use `categories/` as the reference):

| File | Responsibility |
|---|---|
| `*-entity.ts` | Zod schemas and TypeScript types |
| `*-schema.ts` | Drizzle table definition |
| `*-repository-factory.ts` | Raw DB queries |
| `*-service-factory.ts` | Business logic |
| `*-routes-factory.ts` | Fastify route handlers |
| `*-providers.ts` | Wires the domain into the DI container |

### Dependency injection

The DI container (`common/inject/container.ts`) uses factory functions. Each domain's `*-providers.ts` calls `createProviders()` and uses typed wrappers to register routes and schemas:

```ts
export const categoryProviders = createProviders({
  categoryService: categoryServiceFactory,
  categoryRepository: categoryRepositoryFactory,
  ...registerRoutes(categoryRoutesFactory),
  ...registerSchema(categorySchemaRefFactory),
});
```

All providers are composed in `src/app.ts` via `createContainer()`.

### Adding a new domain
1. Create the 6 files following `categories/` as a template
2. Add the providers to the `createContainer()` call in `src/app.ts`
3. Run `npm run db:generate` to create the migration, then `npm run db:migrate`
4. Run `npm run generate:spec` to update `openapi.json`

## Web (`packages/web/`)

### Tech Stack
- **React 19** + **TypeScript** (strict)
- **Vite 7** — root is `src/`, output is `../dist`
- **TanStack Router v1** — file-based routing with route loaders
- **TanStack Query v5** — data fetching and caching
- **TanStack Form v1** — form state management
- **openapi-fetch** — type-safe HTTP client generated from the API's OpenAPI spec
- **Tailwind CSS v4** + **Flowbite** — styling

### HTTP client (`src/core/http/`)

`schema.d.ts` is generated from `packages/api/openapi.json` via `openapi-typescript`. The typed `apiClient` singleton and domain type aliases live in `client.ts`:

```ts
export type Transaction = OkBody<paths["/transactions/"]["get"]>[number];
```

When the API schema changes: regenerate `openapi.json` → regenerate `schema.d.ts`.

### Routing (`src/routes/`)

File-based routing via TanStack Router. `routeTree.gen.ts` is auto-generated by the Vite plugin — do not edit it manually. Route files contain loaders (`ensureQueryData`) that guarantee data is in the cache before the component renders, so page components never handle loading or error states themselves.

### Data layer pattern

Each feature has:
- `*Queries.ts` — `queryOptions` factory + `useQuery` wrapper hook. Use `staleTime: Infinity` for reference data (categories, budgets).
- `*Mutations.ts` — `useMutation` hooks with optimistic updates: cancel queries → snapshot → update cache → rollback on error → invalidate on settled.

### Form system (`src/common/form/`)

TanStack Form via a custom hook factory:
- `formContext.ts` — creates `fieldContext` and `formContext`
- `useForm.tsx` — exports `useAppForm`; register new field types here in `fieldComponents`
- `TextField.tsx`, `SelectField.tsx` — read from `fieldContext`, render input + inline validation errors

To add a new field type: create a component using `useFieldContext()` and register it in `useForm.tsx`.

### Generated files (do not edit manually)
- `src/routeTree.gen.ts` — regenerated on `dev`/`build` by the Vite plugin
- `src/core/http/schema.d.ts` — regenerated via `npm run generate:api-client`
